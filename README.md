# Cannon Game Modifications

## Changes Made

### 1. Faster Projectile and Ball Movement
The speed of both the projectile and the moving balls was increased.

#### Characteristics
- Increased the projectile launch speed by reducing the divisor used in the velocity calculation.
- Increased the horizontal speed of the moving balls.

----------------

### 2. Infinite Gameplay
The game was modified so it never ends when balls leave the screen.

#### Characteristics 
- Removed the condition that stopped the game when a ball exited the window.
- Allowed continuous spawning and recycling of targets for endless gameplay.

-----------------
